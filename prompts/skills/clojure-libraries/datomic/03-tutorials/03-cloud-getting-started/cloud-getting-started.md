# Setup

There are three steps to set up and connect to Datomic Cloud:

- An AWS account administrator [starts a system](../../05-operation/02-cloud/02-start-a-system/start-a-system.md). This is a one-time task.
- An AWS account administrator [configures access](02-configure-access/configure-access.md) for users. This is a one time task.
- [Setup connection](../../05-operation/02-cloud/02-start-a-system/start-a-system.md)

For [Datomic 781-9041](../../11-releases/04-datomic-change-logs/datomic-change-logs.md) and lower, use the [get connected](03-get-connected/get-connected.md) guidance. This task is performed once per client environment (e.g. per developer machine).
